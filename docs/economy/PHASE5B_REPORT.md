## 1. Headline

<!-- generated:summary-headline -->
<!-- /generated:summary-headline -->

What changes for a player, in one paragraph each:

- **Pacing.** The first 20 levels feel the same as today. After Lv 20, each level costs more on a smooth quartic curve (§2), and it replaces today's cliff (Lv 20→50 in under three hours of play). Every gear tier is bought during the stage before its level and equipped on arrival, so a better rod never blocks a level (§6).
- **Catch volume.** A crafted rod no longer lands up to 15 fish. The normal catch averages 1.2 to 1.8 fish per cast by tier, with occasional 3–5 fish jackpots (decision 2). Higher value per fish and XP per rarity carry the difference.
- **Money.** Income comes from fishing, plus quest, streak and buff cash. It pays for:
  - repairs (small, predictable upkeep);
  - one crate assembly per rod tier;
  - one-time biome permits (§7).

  Bait and the aquarium are optional sinks. Players can save (decision 10), and in the reference loop they do: see §13 and decision D3 below.
- **Daily play.** Top.gg voting is retired. A DCC-native streak (Streak Crate / Chest) and typed daily/weekly quests let a casual player keep pace per hour played (§5, §9, §10). A player who logs in only for the daily minimum never overtakes an engaged player (R2).
- **Founder.** Fewer visible fish, the same power through private multipliers, a public level from base XP, and every Founder catch non-competitive (§14).

## 15. Fix-first list (correctness, shipped before any balance change)

Decision 7: bug and exploit fixes are separate from balance tuning and come first. Each is a small correctness change that uses today's numbers.

### 15.1 Already shipped

- **Founder public level-up leak** (standalone hotfix, commit `14e27f1` on `main`, deployed and verified). Before the fix, public `/fish` cards showed "⭐ Level up!" from the Founder's real level, which revealed levels the base XP could not reach. The fix adds an additive `publicXp` field: base catch XP plus base quest XP, never a private bonus. An idempotent migration backfills it from the applied cast journals. Public level-ups, `/profile` and `/inventory` levels now come from it, and the private `/fishing-stats` shows both levels. Eight deterministic tests cover it.
